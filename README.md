# 🎬 YaMDb API

Проект **YaMDb** — это API для сбора отзывов пользователей на различные произведения (фильмы, книги, музыка). Пользователи могут оставлять отзывы, ставить оценки, комментировать отзывы других пользователей. Администраторы управляют категориями, жанрами и произведениями, а также назначают роли пользователям.

## ✨ Основные возможности

- Регистрация и аутентификация по JWT токену (подтверждение через email).
- Пользовательские роли: аноним, аутентифицированный пользователь (user), модератор (moderator), администратор (admin).
- CRUD для произведений (titles), категорий (categories), жанров (genres).
- Отзывы (reviews) и комментарии (comments) к произведениям.
- Рейтинг произведений (средняя оценка на основе отзывов).
- Пагинация, поиск, фильтрация.
- Импорт данных из CSV (для наполнения базы).

## 🛠 Технологии

- Python 3.9+
- Django 3.2+
- Django REST Framework (DRF)
- Simple JWT (аутентификация)
- Django Filter (фильтрация)
- SQLite (по умолчанию), можно использовать PostgreSQL

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-аккаунт/api_yamdb.git
cd api_yamdb
```

### 2. Создание и активация виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
cd api_yamdb
python manage.py migrate
```

### 5. Создание суперпользователя (для доступа в админку)

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

API будет доступно по адресу: `http://127.0.0.1:8000/api/v1/`

Документация ReDoc: `http://127.0.0.1:8000/redoc/`

## 📊 Импорт данных из CSV

В директории `static/data/` находятся файлы с тестовыми данными (категории, жанры, произведения, отзывы, комментарии). Для импорта выполните management-команду (если она реализована):

```bash
python manage.py import_csv
```

Или используйте стандартные средства SQLite.
